Pokemon Games - Data and asset credits

Pokemon data: https://pokeapi.co/docs/v2
Pokemon sprites: https://github.com/PokeAPI/sprites
Pokemon names and characters belong to Nintendo, Creatures and GAME FREAK.
This is an unofficial fan project.

Trainer sprites: https://play.pokemonshowdown.com/sprites/trainers/
Current Alola result portraits are fan-made pixel sprites, bundled unchanged.
Beliot419: selene.png, hau.png, acerola.png, olivia.png, kahili.png, molayne.png, lillie.png.
kyledove: acetrainer-gen7.png, tourist.png.
Artist credits: https://play.pokemonshowdown.com/sprites/trainers/?filter=credited
Used with the directory's attribution requirement; no pixel edits were made.
Alola Champion uses player character Selene's portrait; Hau is a separate tier.
Rank policy and source details: scripts/alola-trainers.md.

Previously bundled Gen IV trainer portraits:
Bundled unchanged: red.png (Red, HGSS), cynthia-gen4.png (Cynthia, DPPt),
volkner.png (Volkner), cheryl.png (Cheryl), acetrainer-gen4dp.png
(DP male Ace Trainer, used by Felix/Butler), youngster-gen4.png
(HGSS Youngster, used by Joey).
Additional unchanged sprites: lance.png, blue.png (HGSS); gardenia.png,
candice.png, roark.png, mira.png, marley.png, acetrainerf-gen4dp.png (DPPt).
The DP female Ace Trainer sprite represents Dana and Sandra on Route 229.
These legacy assets are not selected by the current Alola rank catalog.
Route 229 trainer names and localization references:
https://pokemon.fandom.com/ko/wiki/229%EB%B2%88%EB%8F%84%EB%A1%9C
https://bulbapedia.bulbagarden.net/wiki/Sinnoh_Route_229
These are game sprites, not original artwork created for this project.
Pokinator reuses the unchanged Pokemon sprites from the shared local catalog.
The Alola theme also reuses the catalog's original Alolan Raichu and Rowlet PNGs,
extracted without modification by scripts/export_alola.mjs.
The resort panorama (alola-resort.webp) is AI-generated scenery, not official
Pokemon artwork. Its generation prompt is recorded in scripts/alola-resort-image.md.
The transparent game foliage (resort-foliage.webp) is also AI-generated,
not official Pokemon artwork. Its prompt is in scripts/game-resort-image.md.
Poke Scratch uses the same unchanged sprites. scripts/build_scratch.py reads
their alpha bounds and pixel identities for cropped rendering and fair scoring;
no source artwork is altered.
The homepage's six activity backgrounds are AI-generated resort illustrations.
They are decorative game covers, not screenshots or official Pokemon scenery.
Pokemon artwork on these covers comes from PokeAPI/sprites, under
sprites/pokemon/other/official-artwork (25, 64, 133, 134, 135, 722, 727, 745).
WebP files are resized/encoded copies; characters are not redrawn.
The website positions the artwork over separate backgrounds, using CSS clipping
for the scratch preview and the existing MIT-licensed type icons for the puzzle.
Prompts and asset details: scripts/home-art-images.md.
Pokinator's separate base/regional/Mega answer pool and question matrix are built
from the read-only PokeAPI-derived database by scripts/build_pokinator.py.
Species-level appearance is intentionally unknown for regional and Mega forms.
Pokinator's manually curated franchise questions use original Korean/English
wording. Reviewed facts, bounded scopes and per-question source references are
in data/pokinator-knowledge.json; compiled references are in pokinator.json.
References: PokeAPI Pokedex entries, Pokemon.com movie summaries, Serebii.net
trainer teams, episode guides and game rosters, Bulbapedia movie/cast/box-mascot
references, and the official Smash Bros. Ultimate fighter roster.
These are scoped facts, not a complete history
of every Pokemon appearance. Lore applies to species, not evolution families.
Original character and sprite rights remain with Nintendo, Creatures and
GAME FREAK; the hosting project does not grant rights to Pokemon artwork.

Pokemon similarity scores are generated offline with FastEmbed (Apache-2.0)
and sentence-transformers/all-MiniLM-L6-v2 (Apache-2.0).
https://github.com/qdrant/fastembed
https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2
The embedding model and runtime are not distributed with the website.
Pokemon form descriptions are preferred; species descriptions are used when
form-specific descriptions are unavailable. Missing artwork is not substituted
with artwork of a different form.
